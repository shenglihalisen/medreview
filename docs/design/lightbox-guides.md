# 灯箱辅助线设计（九宫格 / 黄金分割 / 对角交叉线 / 中心十字 / 中心点 / 黄金螺旋）

> 状态：v2 已确认，并已落地实现（`web/app.js` + `web/style.css`，纯前端，无后端/DB 改动）。
> 关联：灯箱原图/预览模式（`isOrig`）、脏点红框（`H` 键切换 `lbHideDirt`，`web/app.js`）。

## 1. 目标

灯箱查看图片（**原图与低清预览都显示**）时，提供可开关的「辅助线」叠加层，帮助构图 / 对齐 / 居中检查。

**已确认需求**：
- 支持以下全部类型，用户可在灯箱内**逐个开关**，**可同时叠加多个**（如九宫格 + 中心点同时显示）。
- 可只开一个，也可多个叠加；全部关掉即不显示。

## 2. 辅助线类型（全部纳入首批）

| key | 名称 | 画法 | 用途 |
| --- | --- | --- | --- |
| `rule-of-thirds` | 三分法 / 九宫格 | 3×3（竖 2 + 横 2，在 1/3、2/3） | 万能构图基准 |
| `golden-ratio` | 黄金分割 | φ 网格（线在 0.382 / 0.618） | 进阶构图 |
| `diagonal` | 对角交叉线 | 两条角到角对角线（X） | 对称 / 对齐 |
| `center-cross` | 中心十字 / 四宫格 | 中线 0.5 处竖 + 横（2×2） | 精准居中、对称 |
| `center-dot` | 中心点 | 画面正中一个圆点 | 单点精准居中 |
| `golden-spiral` | 黄金螺旋 | 对数螺旋路径（SVG `<path>`） | 进阶构图 |

> 架构用 `GuideType` 枚举 + 每种类型的「线段 / 路径列表」描述，新增类型（细密网格 4×4、比例画框 16:9 / 1:1 等）只需加一组数据，零成本扩展。

## 3. 交互

- 灯箱工具栏新增「辅助线」入口（与 `H` 键隐藏脏点框并列）。
- 点击展开一个**清单面板**，列出上述 6 种，每种一个**独立开关**（勾选框 / 拨动）。
  - 每个类型是独立图层，**可任意组合叠加**（如同时勾九宫格 + 中心点）。
  - 全部不勾 = 关掉（不显示任何线）。
- 键盘：`G` 展开 / 收起辅助线面板；面板展开态下，数字键 `1`–`6` 对应切换 6 种类型的开关（盲操友好）。
- 状态 `lbGuides`（各类型 on/off 集合）存入 `localStorage`（同现有偏好记忆），刷新后保持。
- 范围：**原图与低清预览都显示**（取消原仅原图的限制）。

## 4. 渲染（关键技术点）

灯箱当前用 `<img>` + CSS `transform` 做缩放 / 平移；lens-dirt 红框用坐标 boxes 叠加。

- **辅助线必须与图片共用同一 transform**（缩放 / 平移时线跟着走，不漂）。
- 方案：在图片同一变换容器内放一个 **SVG 覆盖层**（`viewBox="0 0 1000 1000"`，坐标用 0–1 比例映射到 1000），每种开启的类型渲染为一组 `<line>` / `<circle>` / `<path>`。
- 线条样式：半透明白 / 黑细线（与脏点红框区分），`pointer-events:none` 不挡交互。
- 坐标用图片宽高比分数，与具体像素 / 缩放无关，天然适配任意尺寸与 zoom。
- 黄金螺旋用 `<path>` 绘制对数螺旋（以画面较短边为基准，螺旋收束于黄金分割点），是唯一非直线类型。

## 5. 与既有脏点框的关系

- 独立图层、独立开关 / 快捷键（`H`=脏点，`G`=辅助线面板），互不干扰。
- 两者可同时显示。

## 6. 需改动文件（纯前端，无后端 / DB 改动）

- `web/app.js`：
  - 新增 `S.lbGuides = {ruleOfThirds:false, goldenRatio:false, diagonal:false, centerCross:false, centerDot:false, goldenSpiral:false}`（localStorage 持久化）。
  - lightbox 渲染：依据 `S.lbGuides` 生成 SVG 覆盖层（复用图片变换容器）。
  - 工具栏「辅助线」按钮 + 展开清单面板（6 个独立开关）。
  - 键处理：新增 `G` 键展开 / 收起面板；`1`–`6` 切换各类型；与既有键并列（参考 `app.js:1498+`）。
- `web/standalone.html`（或 `review.html`）CSS：辅助线样式、面板 / 清单样式。
- 帮助弹窗（约 `app.js:1986`）补「G 辅助线 / 1–6 切换类型」。

## 7. 验收

- 6 种类型均能正确渲染；可任意单选、多选叠加、全关。
- 叠加多层时互不遮挡、清晰可辨。
- 随 zoom / 平移同步、不漂移。
- 开关状态持久化（刷新保持）。
- 与脏点红框可共存；不拦截鼠标。
- 原图与低清预览均显示。
- 无新增后端接口、无 DB 变更。

## 8. 工作量

**0.5–1 天**（纯前端，复用现有灯箱 / 变换 / 偏好机制）。低风险。黄金螺旋的 `<path>` 是唯一略复杂的绘制。
