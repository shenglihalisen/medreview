# 手机端真机手动清单（横屏操作）

自动化能验的都在 `check_mobile_shell.py` 里验过了（静态资源、接口、认领端到端、局域网地址）。
**下面这些只能上真机看** —— 本机没有浏览器自动化，判定是否真命中、遮罩是否真出现、
手指点不点得中，都得你拿手机扫一遍。

准备：

1. 电脑上双击 `start.bat`（或桌面 `素材审阅-启动.bat`），输入素材目录。
2. 启动窗口里会打印一行「手机用这些地址（连同一个 Wi-Fi，记得横屏）」—— 形如
   `http://192.168.x.x:8080/review.html`。同一份地址也写在 `urls.txt` 里。
3. 手机连**同一个 Wi-Fi**，浏览器打开那个地址。

| # | 检查项 | 期望 |
| --- | --- | --- |
| 1 | 能不能打开 | 页面正常渲染，不是转圈或"无法访问" |
| 2 | 自动判定 | 直接进手机版；**加载时不闪一下电脑版布局**。加 `?ui=pc` 立刻变电脑版并记住；`?ui=auto` 恢复自动。同一地址在电脑上打开必须是电脑版 |
| 3 | 竖屏 | 出现「请横屏使用」整屏遮罩，背后布局点不动 |
| 4 | 横屏 | 遮罩消失；左侧文件树常驻；右侧只有 **1 列**；**没有整页横向滚动条** |
| 5 | 卡片 | 图片 + 文件名 + 底部 ✓/○/✕ **同时可见**（不用滚动就能点到按钮）；三个按钮手指点得中 |
| 6 | 名字门禁 | 刷新 → 弹**网页内**弹窗（不是浏览器原生弹窗）；**没有「跳过」**；不填时「开始审阅」是灰的；填完才进得去 |
| 7 | 历史名字下拉 | 第二次刷新 → 输入框右边下拉里有上次填过的名字，选中即自动填入 |
| 8 | 同页锁定 | 进了页面后**没有改名入口**（要改只能刷新） |
| 9 | 关程序失效 | 关掉服务窗口再重启 → 下拉里的历史名字**空了** |
| 10 | 认领 | 点「认领此目录」→ 立刻弹「已认领」、按钮变「释放认领（我）」、左侧那一行**马上出现你的名字** |
| 11 | 认领防双击 | 连点两下**不会**变成「已释放」（不该出现"点了等于没点"） |
| 12 | 认领人显示 | 左侧目录行里，认领人标签紧跟在目录名右边、带浅黄底色、看得清（目录名长时先截断目录名） |
| 13 | 灯箱布局 | 点卡片 → 全屏；**左侧**三个标记键、**右侧**放大/缩小、**底部中间** ‹ 3/14 › |
| 14 | 灯箱缩放 | 「放大」→ 图变大；放大状态下**单指拖动**能移动画面；「缩小」退回 100% 后画面自动归位 |
| 15 | 不误关 | 拖动松手后灯箱**不会**被关掉；只有点图片以外的空白才关 |
| 16 | 自动跳下一张 | 灯箱里点 ✓ → **自动到下一张**；点 ‹ 能往回翻；最后一张点 ✓ 提示「已是最后一张」而不是跳到第一张 |
| 17 | 完成审阅 | 先留几张不标 → 点「完成审阅 · 还有 N 张未定」→ 灯箱**只出现那几张**、标题写「完成审阅 · 还有 N 张未定」→ 一路标完自动关闭；再点一次提示「已全部标记完成」 |
| 18 | 原图确认 | 卡片和灯箱都用原图（高清、能放大看细节），没有糊的缩略图 |
| 19 | 标记闭环 | 手机上点 ✓ → 卡片变色；**电脑上**同目录的计数随之变化 |
| 20 | 后台重连 | 切后台 1 分钟，期间在电脑上标记几张 → 回到手机应自动追平（不用手动刷新） |
| 21 | 安全区 | 刘海/挖孔机型下，灯箱顶栏与底部翻页不被遮挡 |
| 22 | 桌面回归 | **电脑上打开必须跟以前完全一样**：4 列、列数选择器在、右上角有「当前用户: xxx」、灯箱也是左右分栏（这是有意统一的） |

遇到问题怎么定位：

- **手机完全打不开** → Windows 防火墙放行本程序的「专用网络」入站；确认用的是内网 IP 而不是 `127.0.0.1`。
- **点了没反应** → 电脑上的启动窗口里会有 `[claim] folder=… user=… rawXUser=…` 日志：
  有这行说明请求到了服务端；连这行都没有，就是前端没发出去。
- **判定错了**（手机进了电脑版，或电脑进了手机版）→ 用 `?ui=phone` / `?ui=pc` 强制一下，
  顺手把机型和浏览器告诉我，好把判定规则补上。
